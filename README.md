## Welcome to Bento

Welcome to Bento YSWS! Bento is a Hack Club YSWS where you submit your projects with our Bento style requirements, with a bonus for a Logo, and receive free sushi!!! 

You can find out so much more on [bento.hackclub.com](bento.hackclub.com?utm_source=github-repo)

## This Website

This website is hosted on Vercel and is a simple static website. It has multiple pages, including:

- A homepage which lists all the requirements for individuals, the FAQ, the countdown and more!
- The leaders zone where club leaders can get clubs requirements but also the slideshow and document for leading a bento workshop with your club!
- A /submit route which allows individuals to submit their project. This includes `@jeremy46231/ferry` for HCA and Hackatime in submissions.
- Buttons to the organiser's slack account, clubs workshop link, clubs presentation link, clubs document link and to the /submit route
